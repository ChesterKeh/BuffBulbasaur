# Common Table website

Single-file site (`index.html`) built on [Open Props](https://open-props.style/) tokens with Poppins.

## Before going live: edit these (search for `EDIT ME`)
- **`WORK`** (in the `<script>`): the collab portfolio. The six cards are **samples**; replace them with your real collabs and set `sample:false`.
- **Founder note**: the quote and name above "Be part of it".
- **Next supper**: date, venue and price.
- **Contact form**: currently demo-only (shows a thank-you + confetti). Connect it to Formspree, Google Forms or similar.

Ideas for the "Spin the table" game live in `SPIN`; pricing lives in `PRICES`.
